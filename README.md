二、单店版 vs 多店版，差在哪
维度	单店版	多店版
门店管理	无	总部+门店权限
商品	统一	总部统一/门店独立
订单	单店	按门店分流
资金	自己收	平台抽佣、分账、结算
合规	简单	涉及二清风险，必须走分账
多店版最大的坑是资金二清：平台代收各门店货款再结算，没有支付牌照就是二清，违法。合规做法是走微信/支付宝分账。

三、这类源码常见的坑
加密授权：号称开源，核心文件加密，换服务器失效。

后门：eval、base64_decode、远程外链、隐藏管理员账号。

多店资金二清：必须走分账，别碰二清。

存酒是空壳：通用源码里基本没有，宣传图是 P 的。

生鲜称重不支持：需要称重商品、库存、配送时效，通用版没有。

奶茶多规格做不细：杯型/糖度/冰度/加料，很多系统只支持简单规格。

收银台对接不全：小票打印机、钱箱、扫码枪品牌型号要确认。

旧版改名：号称“新版”，实际停更多年。

文档不全：装完没人管，二开无从下手。
